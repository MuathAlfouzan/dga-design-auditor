Use two typography styles: Display and Text.

Use Display text styles at large sizes for headings, not for extended body passages.

Use Text styles for the majority of informational copy, including body text, labels, and UI elements, especially at smaller UI sizes.

Reserve larger Display styles specifically for headings to maintain a clean and organized typographic hierarchy.

Line height

Use line height (leading) to control the vertical space between lines of text.

Adjust line height based on factors like font size and typeface to create a balanced reading experience.

Avoid text appearing cramped or spread out by using appropriate line height.

Tips to effectively use typography (Do / Avoid)

Do: Set an appropriate line height for improved readability. Ensure that text is spaced out enough to avoid crowding while maintaining a comfortable reading experience.

Avoid: Allow lines of text to become excessively long or short. Aim for an optimal line length to maintain readability and prevent user fatigue.

Do: Prioritize readable font sizes for body text. Opt for a comfortable size that ensures legibility without causing strain for a positive user experience.

Avoid: Use excessively small font sizes, especially for body text. Ensure that text is comfortably readable without causing strain.

Avoid: Neglect consistent spacing. Inconsistent margins, padding, or line heights can disrupt the visual flow and make the design feel disjointed.

Accessibility and text colors

Aim to comply with WCAG 2.1 AA accessibility standards.

For accessible color contrast in text:

Use text colors like Gray 500, Gray 600, Gray 700, and Gray 950 for lighter backgrounds with a number 400 and below.

For backgrounds numbered 500 and above, use white text.

Follow WCAG 2.1 minimum contrast ratios:

Level (AA): 4.5:1

Level (AA) for large text (above 18.5 Bold or 24 Regular): 3:1

Level (AAA): 7:1

Level (AAA) for large text (above 18.5 Bold or 24 Regular): 4.5:1
