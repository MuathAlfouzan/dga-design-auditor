Notifications Rules

USE notifications to convey information about updates or changes within the system.



CHOOSE the format based on interaction context: inline, toast, or actionable notifications.



USE Inline Notifications inside task flows to inform users about the status of an ongoing action.



PLACE Inline Notifications at the top of the main content area (within the task flow).



USE Toast Notifications for brief alerts that are transient and non-modal.



PLACE Toast Notifications at the top of the screen and ALLOW them to disappear after a set duration.



TREAT notifications as prominent UI elements that typically appear at the top of a webpage/app screen to draw immediate attention.



IF a Notification/Alert needs further detailed explanation, PUT it in helper text.



IF actions are required, PROVIDE actionable buttons (via an action buttons list).



Modal Rules

USE a Modal as a popup window on top of the main screen to grab attention for immediate actions or input.



INCLUDE focused content (e.g., forms or alerts).



BLOCK interaction with the background until dismissed.



USE Modals for tasks needing confirmation, feedback, or critical alerts to keep focus and simplify interaction.



ENSURE Modals are visually distinguishable with clear visual cues (e.g., prominent titles, distinct design) to improve readability and guide users through tasks.



WHEN a Modal needs a further detailed explanation, PLACE it in the body text/content area.



Tooltip Rules

USE a Tooltip to provide additional information about an element on hover.



SHOW the tooltip as a small box/pop-up near the element.



USE tooltips to explain the purpose of buttons, icons, or interactive elements to enhance understanding and usability.



RESPECT tooltip max width of 240px; text wraps automatically.



SUPPORT tooltip variants: Default, Inverted, and directional variants where the beak is placed Top/Bottom/Left/Right.



Rating Rules

USE Rating to express user satisfaction or opinion (e.g., stars).



APPLY Rating in product reviews and feedback forms to help users make decisions and provide feedback.



SUPPORT Rating states/variants: Normal, Pressed (on click), Selected (active), and Half (between two whole numbers).



Selection Rules

USE Inline Notification when communicating status within an ongoing task flow.



USE Toast Notification for brief, top-of-screen alerts that should auto-dismiss.



USE Modal when the user must focus and confirm/act before continuing (background blocked).



USE Tooltip for hover-based clarification of UI elements.



USE Rating when collecting satisfaction/opinion feedback (including half ratings).
