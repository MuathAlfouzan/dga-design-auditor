Data Display components rules
Avatar

USE Avatar as a visual representation of a user in UI surfaces such as profiles, comments, or messaging apps.



USE Avatar to enhance user engagement and recognition.



Metric

USE Metric in dashboards or reports to highlight trends, comparisons, and numerical values that are critical for monitoring performance over time.



Table

USE Table to display data in a structured format (rows and columns).



USE Table to help users understand and interact with complex information efficiently.



USE Table as a core UI element for experiences that require organizing, analyzing, or manipulating large amounts of data.



Content Switcher

USE Content Switcher to let users navigate between related views efficiently.



USE Content Switcher to display one section at a time to maintain a focused, user-friendly experience.



Charts

USE Charts to visually represent data.



USE pie charts to show parts of a whole as slices.



USE line charts to track trends over time with connected points.



USE bar charts to compare quantities across categories using bars.



USE Charts to provide flexible visualization for clear data insights.



Structured List

USE Structured List to display non-interactive data in a clear, organized format.



ENSURE Structured List maintains consistent formatting, column alignment, and hierarchical organization for easy readability.
